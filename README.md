# Instruções para livros-texto didáticos

| Pasta | Conteúdo |
| --- | --- |
| `livro-didatico/` | O plugin genérico (qualquer assunto): guias, regras, modelos, ferramentas, comandos e agentes revisores. Comece pelo `livro-didatico/README.md`. |
| `.claude-plugin/marketplace.json` | Marketplace local para instalar o plugin: `/plugin marketplace add <esta pasta>` e `/plugin install livro-didatico@instrucoes-livro` |
| `_legado/INSTRUCOES_LIVRO.md` | O guia anterior, num arquivo só, com exemplos do primeiro livro produzido. Fica como referência histórica; não faz parte do plugin. |
