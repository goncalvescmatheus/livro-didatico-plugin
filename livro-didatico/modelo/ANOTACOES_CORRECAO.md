# Anotações de correção

Problemas apontados na leitura do autor, para implementar numa próxima rodada. Ao aplicar: corrija o texto, gere o livro de novo, rode `ferramentas/verificar_livro.py`, marque o item como feito e **procure o mesmo padrão nos outros capítulos**.

Tipos frequentes: número sem origem dita; conversão de unidade ou de base implícita; derivada sem a forma equivalente ou sem a versão para variação finita; símbolo não explicado; sigla obscura; tabela confusa.
