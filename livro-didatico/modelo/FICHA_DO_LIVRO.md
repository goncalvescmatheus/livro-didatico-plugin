# Ficha do livro

Preencha antes de qualquer outra coisa, numa conversa com o autor. Toda decisão didática se apoia nesta ficha.

| Campo | Pergunta-guia | Resposta |
| --- | --- | --- |
| Título e subtítulo | Qual promessa o livro faz ao leitor? | {{TITULO}} — {{SUBTITULO}} |
| Documento de origem | Há ementa, plano de estudo ou programa que o livro desenvolve? | {{origem}} |
| Leitor | Quem é, o que faz, por que vai ler? | {{leitor}} |
| Conhecimento prévio | O que o leitor já domina e serve de ponte? Como se chamará a caixa de ponte? | {{conhecimento_previo}} |
| Objetivo final | O que o leitor deve saber **fazer** ao terminar? | {{objetivo}} |
| Nível | Introdutório, graduação, graduação avançada, mestrado, profissional? | {{nivel}} |
| Idioma | Idioma do texto e idiomas dos equivalentes no glossário | {{IDIOMA}}; {{idiomas_glossario}} |
| Ritmo e volume | Quantos capítulos, em quanto tempo, quantas horas por capítulo, páginas estimadas | {{ritmo}} |
| Caso condutor | Objeto fictício que atravessa o livro (nome que não imite entidade real), com seus parâmetros | {{caso_condutor}} |
| Dados abertos | Que fontes públicas e abertas existem para o assunto? Como se acessam? | {{fontes_dados}} |
| Ferramentas de código | Linguagem e pacotes abertos do laboratório | {{ferramentas}} |
| Restrições | Confidencialidade, fontes proibidas, cuidados éticos ou legais | {{restricoes}} |
| Data de referência | A que data se referem os "hoje" do livro? | {{DATA}} |
| Saídas | PDF e Word (padrão); outras? | PDF, DOCX |

**As restrições valem para texto, código, dados, figuras e casos.**
